# Component sources

components/ui contains MIT-licensed React Native Reusables components from the uniwind registry at https://reactnativereusables.com, by Founded Labs / mrzachnugent. The component APIs are retained; Maia theme tokens and phone control sizes are adapted locally. Item, Field, InputGroup and Empty follow the shadcn/ui components of the same names (MIT). docs/components adapts the React Native Reusables usage documentation, alongside ExaSpark composition guides. See LICENSE.react-native-reusables.
