# Progress

Displays an indicator showing the completion progress of a task, typically displayed as a progress bar. Installed in `components/ui/progress.tsx`; read it for the exact props and classes.

## Usage

```tsx
import { Progress } from "@/components/ui/progress"
```

```tsx
<Progress value={33} />
```
