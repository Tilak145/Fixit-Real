# Label

Renders an accessible label associated with controls. Installed in `components/ui/label.tsx`; read it for the exact props and classes.

## Usage

```tsx
import { Label } from "@/components/ui/label"
```

```tsx
<Label htmlFor="email" nativeID='email'>Your email address</Label>
```
