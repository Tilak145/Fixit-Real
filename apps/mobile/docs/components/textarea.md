# Textarea

Displays a form textarea or a component that looks like a textarea. Installed in `components/ui/textarea.tsx`; read it for the exact props and classes.

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea"
```

```tsx
  <Textarea placeholder="Type your message here." />
```
