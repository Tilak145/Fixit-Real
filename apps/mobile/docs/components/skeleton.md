# Skeleton

Use to show a placeholder while content is loading. Installed in `components/ui/skeleton.tsx`; read it for the exact props and classes.

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton"
```

```tsx
<Skeleton className="h-[20px] w-[100px] rounded-full" />
```
